# はじめに

このアプリは、施策（案件・サービス・共通費などの活動）ごとに、売上・費用の計画と見込を管理するためのものです。毎月、実績が確定するたびに、現場が見込を更新し、FP&A と経営陣が全社の見通しを確かめます。

## ロールとできること {#roles}

| ロール | 主な作業 | 手引き |
| --- | --- | --- |
| 担当者（現場担当） | 担当の施策の数字を毎月更新し、「説明して完了」で報告する | [現場担当の手引き](/manual/member) |
| マネージャー | 所管ユニットの施策を作る・確認する。担当者の役割もある | [マネージャーの手引き](/manual/manager) |
| FP&A | 月次のサイクルを回す（実績の取込・見込の開始・締切・催促）。マスタとシナリオを管理する | [FP&A の手引き](/manual/fpa) |
| 閲覧者（経営陣） | 全社の見込・予実比較・リスク・変更履歴を見る | [予実比較・リスクの読み方](/manual/manager#reports)、[施策の一覧を図で見る](/manual/manager#charts) |

> 人件費など、閲覧制限のある科目の金額は、FP&A と経営陣だけが見られます。担当者・マネージャーの画面では、その科目を合計からも除いて表示し、「閲覧制限のある科目を除いた金額です」と表示します。

## 画面の言葉 {#words}

| 画面の言葉 | 意味 |
| --- | --- |
| 今回の見込 | いま現場が更新している見込の版。画面の上の緑の帯に表示される。現場が入力できるのはこの版だけ |
| 目標 | 比べる基準の計画。修正計画があれば修正計画、なければ期初計画 |
| 前回の見込 | 前の月に締めた見込。今回の見込との差を説明する |
| 実績の月 | 会計の決算が確定し、実績が入っている月（例:「9月まで実績」）。この月までは実績の金額を表示し、入力できない |
| 加重見込 | 金額 × 確度の段階の確率で見積もった見込。リスク画面や予実比較で使う |
| 施策 | 予算・見込を管理する単位。プロジェクト型（案件）・運用型（継続収益）・コストプール型（共通経費）がある |
| ユニット | 施策を束ねる単位（サービス・共通費・管理部門）。マネージャーが所管する |
| 内訳・ドライバー | 科目の金額を分ける単位（内訳）と、金額の根拠となる値（単価・件数など。ドライバー） |

## 毎月の流れ {#cycle}

1. 会計の締めの後、FP&A が実績を取り込み、どの施策のものかを割り当てる
2. FP&A が「月次の見込を始める」。前の版を固定（ロック）し、複製して今回の見込を作り、締切を入れる
3. 担当者に通知が届く。担当者はホームから施策を開き、数字を更新して「説明して完了」を押す
4. FP&A はホームの「今月の作業」で進み具合を確かめ、未完了の人に催促する
5. マネージャー・経営陣は、ホーム・予実比較・リスク画面で見通しを確かめる

## 困ったときは {#help}

- 画面の見出しの横にある「?」で、その画面の説明を開けます。
- 数字の変更はすべて変更履歴に残ります（だれが・いつ・何を・なぜ）。間違えたときも、履歴で前の値を確かめられます。
- 権限や数字の扱いで分からないことは、FP&A に相談してください。
