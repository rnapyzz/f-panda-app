# マネージャーの手引き

マネージャーは、所管ユニットの施策を作り、担当者の更新を見守り、ユニットの見通しを説明します。自分が担当する施策の更新は、[現場担当の手引き](/manual/member)と同じです。

## ホームの見方 {#home}

ホームの「更新する施策」は、初めは「所管ユニット」の施策を表示します（「自分の担当」「すべて」にも切り替えられます）。

### サービスの状況 {#service}

ユニットごとに、今回の見込の年間の利益（または売上）と、期初計画・修正計画・前回の見込との差を並べます。ユニット名を選ぶと、下のカードと一覧がそのユニットに絞り込まれます。

### 変動のサマリー {#changes}

前回の見込から今回の見込で、利益がどれだけ動いたかを、文章・施策別（変動の大きい施策）・要因別にまとめます。担当者が書いた「今回の見込の説明」の抜粋も並ぶので、会議の説明にそのまま使えます。説明がない施策は「説明がありません」と表示します。

気になる説明があれば、施策を開いて説明の下の「**コメント**」に書いてください。担当者にお知らせが届き、返信はあなたにお知らせが届きます。承認ではないので、完了の状態は変わりません。コメントのある施策には、吹き出しと件数が表示されます。

### マイルストーン {#milestones}

変動の大きい施策・重点施策・ウォッチしている施策の、完了していないマイルストーンを並べます。期日を過ぎた・遅延・後ろ倒しになったものは強調します。

## ダッシュボード {#dashboard}

メニューの「**ダッシュボード**」では、見込の状況を図で見て、図を押して掘り下げられます。初めは、マネージャーは所管ユニット、担当者は自分の施策、経営陣・FP&A は全社から始まります（上の「範囲」で広げられます）。

![ダッシュボード](/manual/dashboard.png)

- 上の「比較」で、目標（修正計画、なければ期初計画）か前回の見込を選びます。図や数字には、そのシナリオのエイリアス（例:「期初計画」）やシナリオ名が出ます。
- **年間の状況**: 今回の見込の年間の売上・費用・利益と、比較との差。実績の進み（実績の月の利益 ÷ 年間の見込）。
- **月次の推移**: 月ごとの棒（濃い = 実績の月、淡い = 見込の月）に、目標の線と前回の見込の点線を重ねます。利益・収益・費用を切り替えられます。
- **どこで差が出ているか**: 比較との差を、セグメント → ユニット → 施策の順に横棒で出します。**棒を押すと、画面全体がそこに絞り込まれます**。上のパンくず（全社 › …）で戻れます。
- **前回から何が変わったか**: 前回の見込から今回の見込までの増減を、区分ごと・要因の分類ごと（時期のずれ・新規など）に積み上げます。要因を押すと、その施策だけに絞り込みます。
- **どれくらい確かか**: 楽観・加重見込・悲観の幅と、売上の確度の構成、更新の進み具合。確度の段階を押すと、その段階の施策に絞り込みます。
- **施策**: いまの絞り込みの施策を、比較との差の大きい順に並べます。

どの図も「表で見る」で数字を表にできます。絞り込みは URL に残るので、リンクを送ると同じ画面を共有できます。

## 施策の一覧を図で見る {#charts}

メニューの「施策」で、一覧の上の「表」と図を切り替えます。上の絞り込み（ユニット・タイプ・重点施策など）は図にも効きます。金額は今回の見込の年間です。

| 図 | 見えること |
| --- | --- |
| ポートフォリオ | 横は確度の割合（加重見込 ÷ 満額）、縦は年間の利益、丸の大きさは売上、色は施策のタイプ。右上ほど「確実で利益が大きい」、左上は「利益は大きいが不確か（賭け）」。見込の多くが左側に寄っていれば、計画が楽観的かもしれません |
| ツリーマップ | 面積が売上（または費用）、色が目標との差（青緑は上振れ、赤は下振れ）。どこにお金が集まり、どこが目標からずれているか |
| 振れ幅 | 施策ごとの悲観〜楽観の幅と加重見込。帯が長い施策ほど、見込が確かでない。⚠ は段階に対して状況が悪い施策 |
| 増減の内訳 | 目標（または前回の見込）から今回の見込まで、利益がどの施策でどれだけ動いたか。会議で「なぜずれたか」を説明するのに使えます |
| スケジュール | 施策の期間とマイルストーン。赤い菱形は期日を過ぎた・遅れているもの |
| 確度の推移 | 月ごとの売上を、実績と確度の段階で積み上げたもの。濃い紫ほど確か。下期が淡い色ばかりなら、不確かな見込に頼っています |

丸や四角にカーソルを当てると数字が出て、クリックするとその施策の画面を開きます。

## 施策を作る {#create}

1. メニューの「施策」で「＋ 施策を追加」（所管ユニットだけに作れます）
2. 施策名、ユニット、タイプ（プロジェクト型・運用型・コストプール型）、担当者、確度の段階を入れる（施策コードは空欄なら自動で振られます）
3. 施策の画面の「今回の更新」で、内訳・ドライバーを足して金額を入れる

- プロジェクト型の施策は「**計上の仕方**」を選べます。受託開発のように検収月に売上を一括で計上する案件は「**検収月に一括**」にすると、原価を計上月まで仕掛品に積み、計上月の売上原価と各月の仕掛残高が分かります（[現場担当の手引き](/manual/member#wip)）。選べるのは、FP&A が仕掛品振替の科目を指定してからです。
- 似た施策があるときは、ダイアログの「**既存の施策をコピー**」で選ぶと、内訳（計算式を含む）とドライバーの定義を写して作れます。金額・担当者・日付・マイルストーン・外部コードは写さないので、作った後に入れてください。

- **担当者**を決めると、その人に更新の通知が届き、その人のホームに表示されます。担当者がいない施策は、マネージャーに通知が届きます。
- 終わった施策は、削除せずにステータスを「完了」「中止」にします（金額のある施策は削除できません）。
- **重点施策**（施策の画面の右上）は、会議で必ず見る施策の目印です。**ウォッチ**（☆）は、自分が気にかけている施策の目印です。施策の一覧で絞り込めます。

### 枠の施策（「新規開拓」など）を相手先ごとに分ける {#frame}

計画の時点では「新規開拓」のように相手が決まっていない施策を作り、期中に相手先が見えてきたら、**施策は分けずに内訳で分けます**。目標は元の施策に入っているので、施策を分けると目標と比べにくくなるためです。

1. 計画の時点: 「新規開拓」を1つの施策で作り、「未確定分」などの内訳に目標の金額を入れる
2. 相手先が見えてきたら: 内訳に「α社」「β社」…を足し、内訳ごとに確度の段階と**取引先**を付ける。そのぶん「未確定分」を減らす（加重見込・リスク画面に反映されます）
3. 受注して案件番号が出たら: 施策の「設定」の**外部コード**に、その番号を登録する。会計の明細がこの施策に入ります（番号はいくつでも登録できます）

- 実績は施策 × 科目で集計するので、P/L では相手先ごとに分かれません。相手先ごとの実績は、概要の「実績の明細」の箱の ID（案件番号）と摘要で確かめます。
- 取引先を付けておくと、取引先の画面（設定の「取引先」。内訳の取引先名からも開けます）で、その取引先の施策と内訳を一覧できます。取引先名が変わっても、FP&A が名前を直すだけで紐づきはそのままです。
- デモのデータの「新規開拓（受託）」（DEV-006）がこの例です。

## 予実比較・リスクの読み方 {#reports}

### 予実比較 {#comparison}

- シナリオ（実績の月は実績、それより後は計画値）と実績を並べ、セグメント・組織 → ユニット → 施策とたどれます。
- 「比較元」に選んだ系列との差を表示します。通常は目標（修正計画、なければ期初計画）です。
- 「金額」を「加重見込」にすると、計画値に確度の段階の確率を掛けます（実績はそのまま）。
- 「未割当」の行は、まだどの施策にも割り当てられていない実績です。FP&A が解消します。

### リスク画面 {#risk}

見込がどれくらい確かか、どこに振れ幅があるかを見る画面です。

| 系列 | 意味 |
| --- | --- |
| 楽観 | ベース・アドオンの全額。ダウンサイドは起きない |
| 加重見込 | 金額 × 確度の段階の確率（ダウンサイドも確率を掛ける） |
| 悲観 | 確度の高い段階（A・B）だけ。ダウンサイドは全額 |

- 上の帯で、悲観 ― 加重見込 ― 楽観の幅を見ます。幅が広いほど、見込が確かでない部分が多いということです。
- 「見込の構成」で、売上のうち実績・各段階・ダウンサイドがどれだけあるかを見ます。
- 「施策の一覧」は、振れ幅の大きい順・警告の多い順・比較との差の大きい順に並べ替えられます。行を開くと、内訳ごとの段階、警告、前提条件、今回の見込の説明を確かめられます。

**警告**は、入力を増やさずに、これまでのデータから自動で出します。

| 警告 | 条件 |
| --- | --- |
| マイルストーンの遅れ | 期日を過ぎた、または遅延 |
| マイルストーンの後ろ倒し | 比較シナリオの作成以降に、期日を後ろにずらした |
| 下方修正 | 年間の加重見込の利益が、比較シナリオから 10% 以上かつ 10万円以上下がった |
| 連続の下方修正 | 直近3回の見込で、2回続けて下がった |
| 見込の当たり具合 | 直近3か月で、計画値と実績の差が 20% 以上 |

確度が A・B なのに警告がある施策は「**段階に対して状況が悪い**」として最も強調します。段階が楽観的すぎないか、担当者と話すきっかけにしてください。

![リスク画面](/manual/risk.png)

### 報告資料 {#pack}

経営会議などの資料を作るときは、「報告資料」の画面から出力します。数字は予実比較と同じ集計です。

- **Excel に出力**: 年度・系列（最大4つと実績。1つ目が比較元）・金額（満額か加重見込）・期間・範囲（全社、セグメント、ユニット）を選び、シートを選んで出力します。
  - **全社 P/L**: 科目体系に沿った P/L。期間ごとに、系列と比較元との差を並べます。
  - **ユニット別 P/L**: セグメント → ユニット（施策まで出すこともできます）の売上・利益（通期）と、比較元との差。
  - **変動の説明**: 今回の見込の施策ごとに、目標・前回の見込との差（年間の利益）と、要因・説明を差の大きい順に並べます。
  - 「条件」のシートに、選んだ条件と出力した日時・人が入ります。閲覧制限のある科目は、見られる人にだけ含めます。
- **図を画像で保存**: 報告資料の画面と施策の一覧の図、リスク画面の「サマリー」「見込の構成」にある「画像を保存」で、PNG（白い背景・2倍の解像度）を保存できます。スライドにそのまま貼れます。Chrome か Edge を使ってください。
