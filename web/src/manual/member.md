# 現場担当の手引き

毎月の見込の更新は、**ホームから施策を開き、数字を直して、説明して完了する**だけで終わります。

## 毎月の更新の流れ {#update}

1. 「見込の更新が始まりました」の通知（ベルと Slack）が届いたら、**ホーム**を開く
2. 「更新する施策」の一覧から、状態が「未着手」「入力中」の施策を選ぶ（施策の「今回の更新」タブが開く）
3. 期日を過ぎたマイルストーンがあれば、上に表示される。「概要で更新する」から状況を直す
4. 数字の表で、実績の月より後の月を直して「保存」する
5. 「目標・前回の見込との比較」で、差を確かめる
6. 「今回の見込の説明」に差の理由を書き、「説明して完了」を押す

締切までに完了しないと、締切の前と、締切を過ぎてから毎日、通知が届きます。

![ホーム（担当者）: 更新する施策の一覧](/manual/home-member.png)

## ホームの見方 {#home}

- 上に、今回の見込・目標・前回の見込と、締切を表示します。
- 「実績のお知らせ」: 新しい月の実績が入ったときに表示します。前回の見込との差が大きい（前回の見込の 20% 以上）施策は、特に見直してください。
- 「更新する施策」: 状態は 未着手 → 入力中（数字や説明を変えた）→ 完了（説明して完了を押した）。「自分の担当」「すべて」を切り替えられます。並べ替えで、目標・前回の見込との差の大きい順にもできます。

## 施策の画面 {#activity}

施策の画面には3つのタブがあります。

| タブ | 内容 |
| --- | --- |
| 今回の更新 | 数字の入力、目標・前回の見込との比較、今回の見込の説明。普段はここだけで作業できます |
| 概要 | P/L（目標と最新の比較）、実績の明細（すべての月を新しい順に表示。年度・月・科目で絞り込み、CSV に出力できます）、マイルストーン、前提条件 |
| 設定 | 基本情報、内訳・ドライバーの一覧、外部コード |

画面の右上で、表示するシナリオを切り替えられます。いつもは今回の見込が選ばれています。今回の見込以外のシナリオは参照だけです。

![施策の画面: 今回の更新](/manual/activity-update.png)

## 数字の入力 {#input}

表はスプレッドシートと同じように使えます。

- セルを選んでそのまま入力します。Enter・F2・ダブルクリックで編集。Enter で下へ、Tab で右へ
- Shift+クリック・ドラッグで範囲を選び、Excel・Google スプレッドシートとコピー・貼り付けできます（1,000 や △1,000 も可）
- Ctrl/⌘+R で右へ、Ctrl/⌘+D で下へコピー。Delete で消去。Ctrl/⌘+Z で元に戻す
- 変更すると、下に「N 件の変更」と「保存」が出ます。**変更理由は空欄でも保存できます**（「（今回の見込の名前）の見込更新」と記録されます）。特別な理由があれば書いてください

> 実績の月（例: 9月まで実績）の金額は会計の実績で、入力できません。灰色の列です。

### 金額の行 {#amounts}

- 科目の金額は、**内訳**と「その他」（科目に直接入れた金額）の合計です。
- 表にない科目は「＋ 科目を追加…」で選ぶと、行が増えます。
- `fx` の付いた内訳は、ドライバーと計算式から自動で計算されます（直接は入力できません）。ドライバーの値を変えると、保存する前に試算した金額が色付きで表示されます。

### 内訳・ドライバーを追加する {#lines}

- 「＋ 内訳を追加」: 科目と内訳名（例: 月額利用料、初期導入費）を入れます。「金額の入れ方」で「計算式で反映」を選ぶと、ドライバーのコードを使った式（例: `unit_price * customers`）で金額を計算します。式を設定するときは理由が必要です。
- 「＋ ドライバーを追加」: 名称、コード（式で使う名前。半角英数字）、種別（バリュードライバー・コストドライバー・KPI）、単位を入れます。
- 計算式・確度の段階などの詳しい変更や削除は、「設定」タブの一覧で行います。

### 確度の段階と見通しの種類 {#confidence}

施策や内訳の金額が、どれくらい確かかを付けます。加重見込・楽観・悲観の計算に使います。

| 段階 | 目安 | 確率 |
| --- | --- | --- |
| A 確定 | 契約・発注済み、または継続契約中 | 100% |
| B 高 | 内示・口頭合意がある | 80% |
| C 中 | 見積・提案書を提出済み | 50% |
| D 低 | 引き合い・初回提案の段階 | 20% |
| E 構想 | 具体的な相手先・計画がない | 0% |

- 施策の段階は「設定」の基本情報で、内訳ごとの段階は内訳の「詳細設定」で変えます（指定しなければ施策と同じ）。
- 見通しの種類（内訳の「詳細設定」）: **ベース**（既存の契約・顧客から見込める分）、**アドオン**（新しい活動・追加要件による上積み）、**ダウンサイド**（不利な出来事による減少。金額はマイナス）。
- 段階を変えるときは理由が必要です。根拠のない楽観や控えめすぎる見込は、リスク画面の警告で分かるようになっています。

### 仮の値 {#provisional}

見積待ちなどで、確定していない値を仮に入れるときは、セルを選んで下の「詳細設定（仮の値）」で「仮の値」にし、理由を書きます。

## 今回の見込の説明と完了 {#note}

- 左に、目標・前回の見込との年間の差と、差の大きい科目・月が自動で表示されます。これを見ながら書いてください。
- 「要因の分類」（時期のずれ・数量・単価の増減・新規・失注・解約・前提の変化・その他）を選び、説明を書きます。想定している条件（楽観・悲観の見通しなど）もここに書きます。
- 「**説明して完了**」で、今回の更新が終わったことを記録します。途中で止めるときは「下書き保存」。
- 未保存の数字の変更があると、完了にできません。先に「保存」してください。
- 完了した後に数字や説明を変えると、状態は「入力中」に戻ります。もう一度「説明して完了」を押してください。

![今回の見込の説明](/manual/activity-note.png)

### コメント {#comments}

- 説明の下の「コメント」で、マネージャーや FP&A とやり取りできます。だれかがコメントを書くと、担当者にアプリ内のお知らせ（上のベル）が届きます。
- 質問されたら、コメントで返すか、説明そのものを書き足してください。コメントを書いても、状態（未着手・入力中・完了）は変わりません。
- 自分のコメントは「削除」で消せます。ロックされたシナリオには書けません。

## 計画値の CSV {#csv}

期初計画など、まとめて入力したいときは Excel で編集できます。ホームの上の「今回の見込」の名前から、シナリオの画面を開きます。

1. 「計画値の CSV」で「金額を出力」または「ドライバー値を出力」（ユニットで絞り込めます）
2. Excel で編集する。空欄は「変えない」、`-` は「消す」、数字は「その値にする」
3. 「CSV を取り込む」でファイルを選び、「内容を確認」で追加・更新・削除の件数を確かめてから「取り込む」

> 実績の月の値と、計算式で反映する内訳の値は取り込まれません。担当していない施策の行は、値を変えるとエラーになります。

## よくある質問 {#faq}

**入力できない月がある**: 実績の月は会計の実績なので入力できません。今回の見込以外のシナリオも、担当者は入力できません。

**完了が「入力中」に戻った**: 完了の後に、数字か説明が変わりました（ほかの人が直した場合も含みます）。変更履歴で確かめて、もう一度「説明して完了」を押してください。

**目標・前回の見込が「未設定」**: FP&A がシナリオの設定をしていません。FP&A に連絡してください。

**一覧に出てこない施策がある**: ステータスが「完了」「中止」の施策は、今後の月に金額が残っているときだけ表示します。

**変更履歴はどこ？**: 施策の画面の右上の「変更履歴」から、その施策の履歴を見られます。
